A.S.T.R.A. Space

On long missions, crew members need to understand their exercise results and see which training plan has been approved on board. ASTRA links the station that reviews the results to the crew member’s personal companion.

Try the workflow

  1. Open the Expo companion and select the fictional profile Inès. Her cycling target is 100 W.
  2. Open Profil et station and import CEVIS session 3. Calculate the adjustment and complete the two simulated reviews.
  3. Return to Mon suivi. Tap GO to see the approved 105 W plan. Ask a guided question, then open Mon chat to see Nova’s progress.

Each browser has a temporary workspace. This release uses a simulated cycling device and local answers. The NASA Exercise Overview provides scientific context for the design. The example targets are fictional.
